# ECHOLIVITY visual identity

The SDD-3000 project uses a restrained instrument-panel language: graphite surfaces, warm amber signal indicators and a cool cyan accent for modern/extension functions.

| Role | Colour | Use |
|---|---|---|
| Graphite | #111820 / #202B32 | Primary backgrounds |
| Warm amber | #F4B84B | Primary signal, headings and emphasis |
| Soft ivory | #F5F2E9 | Main text on dark surfaces |
| Slate | #9FB0B7 | Secondary text |
| Signal cyan | #62C6D0 | Modern additions and secondary signal |

## Asset use

- echolivity-sdd3000-banner.svg is the project masthead.
- ../ui_preview.png is the actual device-interface preview. Keep it distinct from promotional artwork.
- Prefer screenshots captured from the current release candidate. Label the version and host when adding captures.
- Do not use Korg logos, trade dress or copied product photography. This project is an independent homage.

## Documentation conventions

Use the same masthead and compact navigation on user-facing guides. Keep technical reports text-first: status, evidence and caveats must remain easy to scan. Amber indicates project identity; cyan is reserved for modern extensions, not pass/fail status.
